# 🚀 Smart Resume Builder with AI Suggestions

A minimalist, high-performance web application designed to help job seekers build professional, ATS-friendly resumes in real time. Features live side-by-side previewing, automated AI content refinement (via Gemini API), and instant vector PDF export functionality.

### ✨ Key Features
- **Live Interactive Preview**: Instant side-by-side editing and real-time document rendering.
- **AI Content Enhancements**: Refines professional summaries and work experience bullet points.
- **Pixel-Perfect PDF Export**: Uses clean browser print stylesheets (`@media print`) for high-quality downloads without heavy dependencies.
- **Fully Responsive & Accessible**: Mobile-first design built with modern React 18 hooks and Tailwind CSS.

### 🛠️ Tech Stack
- **Frontend**: React 18, Tailwind CSS, Lucide Icons
- **Build Tool**: Vite
- **AI Integration**: Google Gemini API (with offline fallback logic)
